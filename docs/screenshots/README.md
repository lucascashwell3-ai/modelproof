# PR screenshots

Rendered evidence for pull requests, so review can happen by looking rather than by reading
code. Captured with Playwright against a local `python3 -m http.server` run of the real site.

Keep these small — resize to ~1400px wide and save as JPEG (quality ~78). A repo this size
shouldn't carry multi-megabyte PNGs in its history. Replace rather than accumulate: one set
per visual change, named for the feature.
